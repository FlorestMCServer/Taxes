# Taxes Plugin

Плагин для Minecraft-сервера (Bukkit/Spigot/Paper), добавляющий систему налогов. Лидеры стран могут взимать налоги со своих граждан — как со всех сразу, так и с конкретного игрока. Экономика работает через Vault.

## Требования

- Сервер: Bukkit / Spigot / Paper
- Java 17+
- Vault (обязательно)
- PassportManager (обязательно)
- Любой плагин экономики, поддерживающий Vault

## Установка

1. Убедитесь, что на сервере установлены Vault и PassportManager.
2. Поместите Taxes.jar в папку plugins/.
3. Перезапустите сервер.
4. Проверьте логи — при успешной инициализации вы увидите:
   [Economy] INITIALIZED!
   Ready to work!

## Команды

### /tax <country|person> <название_страны> <сумма> [ник_игрока]

Снимает налог с граждан страны. Команда доступна только лидеру указанной страны.

Вариант 1. Собрать налог со всех граждан страны:
/tax country <название_страны> <сумма>
- Со всех граждан, у которых достаточно средств, списывается указанная сумма.
- Все собранные средства переводятся на счёт лидера.
- Лидеру выводится сообщение о количестве заплативших и общей сумме.

Вариант 2. Снять налог с конкретного игрока:
/tax person <название_страны> <сумма> <ник_игрока>
- Списывает указанную сумму только с одного гражданина.
- Если у игрока недостаточно средств — операция отменяется.

## Права и условия

- Команду может использовать только лидер страны, указанной в аргументе.
- Нельзя взимать налог с несуществующей страны.
- Нельзя снять налог с игрока, не являющегося гражданином указанной страны.
- Если у гражданина недостаточно средств, налог с него не списывается (при массовом сборе — пропускается).

## Автодополнение (Tab)

Плагин поддерживает автодополнение аргументов:
- Аргумент 1: country, person
- Аргумент 2: список существующих стран
- Аргумент 3: <сумма>
- Аргумент 4: ники граждан выбранной страны

## Как это работает

1. При старте плагина Taxes загружается список стран из базы PassportManager.
2. EconomyManager подключается к Vault и получает провайдера экономики.
3. При вызове /tax:
   - Проверяется существование страны.
   - Проверяется, что отправитель — лидер этой страны.
   - Производится списание средств через EconomyManager.withdraw(...).
   - Средства зачисляются лидеру через EconomyManager.depositPlayer(...).

## Структура проекта

ru.florestdev.taxes

- CommandActivity.java — обработка команды /tax и автодополнение
- EconomyManager.java — обёртка над Vault Economy

## Примечания

- Если Vault или экономический плагин не найден, EconomyManager работает в режиме заглушки: canAfford всегда возвращает true, а withdraw/deposit не выполняют реальных операций.
- Список стран формируется один раз при включении плагина. При добавлении новых стран потребуется перезагрузка сервера.
- Формула подсчёта собранных средств в режиме массового сбора: количество_заплативших × сумма_налога.

## Известные ограничения

- В сообщении о массовом сборе сумма выводится как players_gave * Integer.parseInt(count) — при дробной сумме налога это может привести к ошибке парсинга. Рекомендуется использовать целые числа.
- Список стран plugin.countries не обновляется в реальном времени.
